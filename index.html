Dashboard

Associate cards show only non-leadership staff. Leadership appears in the "Meet Your Leadership Team" section above. Cards are sorted alphabetically. Use the search bar to find by name or employee ID, or filter by shift, status, flag, or certification.

The stats bar shows: Active (all active roster), Associates (excluding leadership), In Building (active minus today's call-outs and early-outs), and Call Outs / Early Outs for today.

Card Banners

Cards show a single colored banner for the associate's current status today. Attendance events take priority: NCNS, OUT (call-out), Early Out, Tardy. If no attendance event, the time-off type shows: Vacation, FMLA / Medical, Bereavement, etc. Only one banner appears at a time. Banners reset automatically each day.

Associate Profiles

Click any card to open a profile. From there you can add manager notes, toggle certifications, nominate badges, log attendance, schedule 1:1 meetings, and manage time off. Use Export PDF to generate a printable HR summary.

Note Types

Coaching: 0 pts. Recognition: +10 pts. Leadership: +15 pts. Warning: −10 pts. PIP: −150 pts. General: 0 pts.

Achievement Badges

Leads, Supervisors, and Admins can nominate associates for badges. Each nomination requires a reason and goes to an Admin for approval. Once approved, points are awarded automatically. Badges stack — an associate can earn the same badge multiple times.

Tiers: Standard (25 pts) · Productivity (60–200 pts based on units) · Elite/Leadership List (200 pts) · Employee of the Month (300 pts). Productivity badges cover Large Pack (300–500 units), Small Pack (600–1000 units), Replen Pick (1000 units), and OP Pick (600 units).

Certifications

Leads, Supervisors, and Admins can toggle certifications on each profile. Each cert earned adds +10 points; removing one deducts 10. There are 26 certifications available covering all major warehouse roles. Use the cert filter on the dashboard to see who is qualified for a specific role.

Private Watch Notes

The amber dashed section at the bottom of each profile is only visible to Supervisors and Admins. Use it to track attendance patterns, early departures, tardiness, or behavioral observations you don't want in the general notes feed. These notes do not affect points.

Time Off Calendar

The Time Off sidebar tab lets supervisors and admins schedule and track associate time away.

  • Calendar View: Click any day to add an entry pre-filled with that date.
  • Types: Vacation, Sick, Personal, FMLA, Bereavement, Leave of Absence, Out (Other), Unpaid.
  • Card Banners: When an entry is active today, a banner appears on the associate's card. Only one banner shows at a time — attendance events take priority.
  • Upcoming Events: Entries within the next 40 days also appear in the Upcoming Events dashboard panel.

Time off and attendance logs are independent. Adding FMLA or Bereavement to both systems will not create duplicate banners or double-count points.

HR Records

The HR Records tab stores all signed corrective action forms. Each record shows the associate name, warning tier, points at time of signing, and signature status.

  • Submit to HR: A blue button under each associate's name lets you log the date the form was physically submitted to HR. Once clicked, it stamps the date and turns green — persists across sessions.
  • View / PDF: Open the full signed form or download it as a PDF.
  • Filter: Search by name or filter by warning tier.
1:1 Meetings

On any associate profile, the 1:1 Meetings panel lets you schedule upcoming meetings and log completed ones. The badge count reflects both scheduled and completed meetings combined. When a supervisor logs in, a pulsing banner appears if any direct report has a pending 1:1 request. Completed meetings are stored in history and visible on the associate's mobile portal under the Schedule tab.

Associate Mobile Portal

Associates can log in to a mobile-friendly portal using credentials created by an admin. The portal gives read-only access to their own data — they cannot see other associates' information.

Granting access: In the Admin Panel → Portal Access Management, enter the associate's email and click Grant Access. The system creates their login and sends a password reset email automatically. Associates can also request access from the login page.

Shift Snapshots

Import productivity snapshots via the Import Snapshot button on the dashboard. Three methods available:

  • Upload Image: OCR extracts the data automatically from a screenshot.
  • Paste Snapshot: Copy and paste the shift report text.
  • Manual Entry: Type Employee ID, date, UPH, and units directly.
Team Attendance Tracker

The Attendance sidebar shows a team-wide view of all logged events.

  • At-Risk Panel: Up to 8 associates with the most points, with policy step labels.
  • Period Filter: This Week, This Month, This Year, or All Time.
  • Log Table: Filter by associate, shift, event type, and date range.
  • Calendar: Visual month view of which days had events.
System Credentials

The System Credentials panel stores system logins (WMS, scheduler, etc.) per associate. Leads and above can add entries; only Admins can delete. Passwords are masked by default — click the eye icon to reveal. Not visible to Viewer-role accounts.

Corrective Action Form

When an associate reaches a warning threshold on the Attendance tab, a Print Corrective Action button appears. The generated form includes:

  • Associate name, employee ID, hire date, shift
  • Warning tier and pre-filled attendance summary
  • Signature lines and previous discipline history

Run Expiry Check Now

Scans all associates for engagement and attendance points older than 1 year and expires them immediately. Shows a detailed list of every entry zeroed out. Use this if the automatic expiry on dashboard load doesn't seem to be running.

Expiry Diagnostics

Shows stored vs. computed expiry dates for all associates. Highlights mismatches so you know exactly who needs the backfill.

Backfill Expiry Dates

One-time setup. Reads existing attendance and points data for all associates and writes their upcoming expiry dates directly to their profile. This lets the Upcoming Events panel show expiry alerts without expensive Firestore reads. Run this once after deploying — never needed again.

Fix NCNS Entries

One-time fix for imported records where type was saved as "Call Out" but points = 2 (should be NCNS). Scans all attendance entries and corrects the type field to "ncns". Run once after deploying the NCNS update.

Recalculate Attendance Points

Re-totals each associate's attendance points directly from their entry records and corrects the stored counter if it has drifted. Run this after any bulk delete + re-import or if a profile's Attendance Pts display looks wrong.
